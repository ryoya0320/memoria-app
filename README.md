# Memoria v23 IDログイン版

メール認証・GitHub認証を削除し、IDとパスワードをこの端末内で作成する方式に変更しました。

## 特徴
- メールアドレス不要
- IDは3〜24文字の英数字・アンダースコア・ハイフン
- パスワードは6文字以上
- パスワードはPBKDF2でハッシュ化して保存
- 既存のプロフィール、カレンダー、アルバム、DMなどは維持

## 大切な注意
IDとパスワードはブラウザ内に保存されます。別端末への引き継ぎ、Safariの履歴・Webサイトデータ削除後の復元、パスワード再発行はできません。これはサーバー認証ではなく、端末内の簡易ロックです。

## 置き換え
ZIP内の index.html / style.css / app.js をGitHubへ上書きしてください。config.jsなど他のファイルは削除しないでください。
