# Memoria v6 完全置き換え版

GitHub上の同名ファイルを、このZIP内のファイルで丸ごと置き換えてください。`icon.png` は今の画像をそのまま残してください。

## 追加機能
- 写真フォルダから複数枚を一括選択、一括プレビュー、一括保存
- カメラ撮影は従来どおり1枚ずつ
- プロフィールから文字サイズを4段階で変更して保存
- カレンダーの日付をタップすると、予定と写真の詳細をダイアログ表示
- 詳細内の写真をタップすると全画面表示
- v5の共有、アイコン切り抜き、テーマ連動イラスト、フォント、アルバム機能を維持

## 重要
すでにSupabase接続済みなら、GitHub上の現在の `config.js` は上書きせず残してください。ZIP内の `config.js` は空欄です。
