# Memoria v7 修正版

今回はSafariのキャッシュを避けるため、CSSとJavaScriptのファイル名を `style-v7.css` と `script-v7.js` に変更しました。ZIP内のファイルをすべてアップロードしてください。ただし、Supabase設定済みの現在の `config.js` と現在の `icon.png` は残してください。

## 修正
- iPhone Safariで確実に開きやすい、ラベル直結型の複数写真選択
- FileReader方式による複数写真プレビュー
- 選択枚数、番号、選択解除、一括保存、保存中表示
- カレンダー日付タップで詳細ダイアログと画面内一覧の両方を表示
- 予定保存直後に詳細一覧を更新
- 文字サイズをHTMLルートへ14/16/18/20pxで即時適用し保存
- 既存の共有、テーマ、フォント、アイコン切り抜きなどは維持
