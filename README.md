# Memoria v17 いちから作成した完全版

過去ファイルを継ぎ足さず、HTML・CSS・JavaScriptを新規作成しました。

## 含まれる機能
- ホーム、カレンダー、追加、アルバム、プロフィール
- カレンダー予定と25種類の白・灰色系マーク
- 複数写真、アルバム、最近の思い出
- 友だちID、ID申請、承認、複数人との個別DM
- 名前、プロフィール画像、送信時刻、既読・未読
- DM背景色・背景画像
- 招待コードによるアルバム、カレンダー、リスト、記念日の共有
- 左側のMemoria画像付き友だち追加はありません。右上の人物＋アイコンのみです。

## 設置
1. 既存リポジトリのファイルをバックアップします。
2. ZIP内のファイルをすべてGitHubへアップロードします。
3. `config.js` にSupabase URLとAnon Keyを入力します。
4. Supabase SQL Editorで `supabase-setup.sql` を1回実行します。

注意: このSQLは個人開発用プロトタイプです。本番公開前にはSupabase Authと厳格なRLSへ変更してください。
